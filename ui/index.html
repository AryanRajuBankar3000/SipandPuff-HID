About the Project

Building accessible technology, one breath at a time

🎯

Purpose

This Sip & Puff mouse controller is an assistive device designed for individuals with motor disabilities. By interpreting gentle breath pressure through an HX710B sensor, users can control their computer cursor without hands.

⚙️

How It Works

The HX710B pressure sensor converts breath into a 24-bit digital value. The RP2040 reads this via a clocked serial protocol, subtracts a running baseline, classifies the delta as soft/hard sip/puff, and sends USB HID mouse reports at ~100 Hz.

🔧

Tech Stack

Hardware: Raspberry Pi Pico W, HX710B ADC
Firmware: C with Pico SDK + TinyUSB
UI: Vanilla HTML/CSS/JS with Web Serial API

♿

Accessibility

Designed with universal access in mind — standard USB HID compatibility means it works on any operating system without drivers. This dashboard uses Web Serial for configuration and testing.
